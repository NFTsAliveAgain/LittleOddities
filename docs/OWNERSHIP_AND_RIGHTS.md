# Ownership, Rights & Handover

*Not legal advice. Have a lawyer review before relying on any of this.*

## What the founder must personally own and control
| Asset | Where | Action |
|---|---|---|
| GitHub repository | Founder's GitHub account | Create repo, push this code, enable 2FA |
| Domain | Registrar account in founder's name | Auto-renew, 2FA, registrar lock |
| Website hosting | Vercel account | Founder is owner; helpers invited as members |
| Database | Turso account | Founder owns |
| IPFS | Pinata (+ backup) account | Founder owns API keys |
| Smart contract | `owner()` = founder's owner wallet | Verify on Etherscan after deploy |
| Deployer wallet | Founder | Separate, low balance |
| Social accounts | X, Discord, Instagram… | Founder's email, 2FA, recovery codes stored offline |
| Artwork + source files | Founder's storage (cloud + offline backup) | Receive PSD/Procreate sources from artist |
| Documentation | This repo | — |

The contract has **no developer backdoor**: the only privileged account is `owner()`. Ownership moves
with `transferOwnership(new)` + `acceptOwnership()` from the new wallet (two-step, so typos can't lose it).

## Artwork rights
- The artist owns their work **unless** a written agreement assigns it. Before final payment, get a signed
  **Copyright Assignment / Work-for-hire agreement** covering: all layers, sources, concept art; worldwide,
  exclusive, perpetual rights; right to sell as NFTs, license to holders, and make derivatives; moral-rights waiver
  where allowed; warranty of originality; **AI-use disclosure**; no reuse of the art elsewhere.
- **AI-generated material:** under current US Copyright Office guidance, material generated by AI without
  sufficient human authorship may not be protected by copyright. Get written disclosure and legal advice.
- Code written by Claude in this repo is provided for the founder's project; open-source dependencies keep their own
  licences (OpenZeppelin MIT, Next.js MIT, fonts SIL OFL, etc.).

## NFT holder license
Draft on `/license`: personal use + limited commercial use while you hold the NFT; copyright is **not** transferred.

## Contractor checklist
- [ ] Signed agreement before work starts  - [ ] Rights assignment signed before final payment
- [ ] AI disclosure  - [ ] Source files delivered  - [ ] Invoice + payment records kept

## Handover checklist (when Claude/other developers finish)
- [ ] Repo in founder's GitHub; founder is sole admin
- [ ] All environment variables known to founder (stored in a password manager)
- [ ] Founder can run `npx hardhat test` and `npm run dev` (or knows who can)
- [ ] Contract owner = founder's wallet (checked on Etherscan)
- [ ] Every account above lists the founder as owner
